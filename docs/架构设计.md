# 《枪法守城闯大关》架构设计（v1）

> 依据：`docs/manual_extract.md`（开发手册 v1.2 全文）。工程：Unity 2022.3.62f3c1 / 2D URP / C#。
> 所有代码遵守 `AGENTS.md` 的 5 条规范（命名、中文 [Header]/[Tooltip]、注释、// TODO:、及时沟通）。

## 1. 分层原则

```
表现层 (MonoBehaviour + uGUI + SpriteRenderer)   ← View / UI / Audio / Art
        ↑ 每帧拉取状态 + 订阅一次性事件
模拟层 (纯 C#，无 UnityEngine 依赖除 Vector2/Mathf) ← Core / Combat / Waves / Run / Save / Analytics
```

- **模拟层不挂 MonoBehaviour、不读 Time.time、不碰渲染**：便于批处理模式跑无头测试（QA 已验证）。
- **视图层只读模拟状态**：实体（敌人 / 子弹）用 `id` 与对象池对齐；一次性反馈（击杀特效、飘字、音效）走事件。
- 数值全部来自 `Assets/Resources/Config/*.json`，代码中不出现魔法数字（除 0/1 等结构常量）。

## 2. 世界坐标约定（固定，不允许各处自定义）

| 项 | 值 | 说明 |
|---|---|---|
| 像素→世界单位 | 100 px = 1 unit | 手册数值单位是 px/s，直接 /100 |
| 屏幕 | 10.8 × 19.2 unit | 竖屏 9:16，正交相机 size = 9.6 |
| 底部固定发射点 muzzle | (0, -8.2) | 城墙炮台 |
| 城门（受击线） | y = -8.6 | 敌人到达 y ≤ -7.4 开始攻击城门 |
| 敌人出生线 | y = +10.6 | 从上往下走 |
| 城门血条 | 顶部 UI | 不在世界内 |

## 4. 核心类型契约（lead 已实现，直接引用，不要修改）

```csharp
namespace Gunplay.Core {
  public enum GameState { Menu, Battle, Result, Shop, GameOver }
  public enum DamageType { Normal, Explosive, Piercing }
  public enum EnemyKind { Grunt, Runner, Shield, Flyer, Heavy, Boss }
  public enum UpgradeKind { Damage, FireRate, Pellets, Pierce, Magazine, Crit, ComboWindow }
  public enum ShopOfferKind { Weapon, Wall, Upgrade }

  // 事件（class，字段只读，事件总线按类型分发）
  public sealed class EnemyKilledEvent { public int Id; public EnemyKind Kind; public Vector2 Pos; public int Gold; public int Combo; }
  public sealed class EnemySpawnedEvent { public int Id; public EnemyKind Kind; public Vector2 Pos; public float MaxHp; }
  public sealed class EnemyDamagedEvent { public int Id; public float Damage; public bool Crit; public Vector2 Pos; }
  public sealed class ShieldBlockedEvent { public int Id; public Vector2 Pos; }
  public sealed class ShieldBrokenEvent { public int Id; public Vector2 Pos; }
  public sealed class ExplosionEvent { public Vector2 Pos; public float Radius; }
  public sealed class GateDamagedEvent { public float Damage; public float GateHp; }
  public sealed class GoldChangedEvent { public int Gold; public int Delta; }
  public sealed class ComboChangedEvent { public int Combo; public float Multiplier; }
  public sealed class WaveStartedEvent { public int Level; public int Wave; public int WaveCount; public bool BossWave; }
  public sealed class WaveClearedEvent { public int Level; public int Wave; public int Reward; }
  public sealed class LevelClearedEvent { public int Level; public int Reward; public LevelStats Stats; }
  public sealed class GameStateChangedEvent { public GameState Previous; public GameState Current; }
  public sealed class ShopRolledEvent { public IReadOnlyList<ShopOffer> Offers; public int RerollCount; }
  public sealed class ShopPurchasedEvent { public ShopOffer Offer; }
}
```

## 6. 状态机

```
Menu --StartNewRun()--> Battle --(关卡全波次清空)--> Result --EnterShop()--> Shop --NextLevel()--> Battle
Battle --(城门 HP ≤ 0)--> GameOver --RestartRun()--> Battle / --BackToMenu()--> Menu
```
不允许任何「复活 / 重试本关」分支。

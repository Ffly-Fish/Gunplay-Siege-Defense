# 交付说明 —— 枪法守城闯大关（Gunplay Siege Defense）

竖屏 9:16 定点守城射击小游戏，Unity 2022.3.62f3c1 + 2D URP，目标平台：抖音小游戏（WebGL）。
本版按 `docs/manual_extract.md`（开发手册 v1.2 抽取稿）实现全部核心玩法与数值。

## 一、怎么玩

- **瞄准与开火**：第一根手指按下屏幕，炮口立刻转向该点；按住持续朝该方向齐射，抬起停火。屏幕上按住也可以拖动改变朝向。
- **城墙**：底部城墙有耐久，敌人碰到城墙掉耐久；耐久归零即本局结束。
- **连杀**：短时间内连续击杀触发倍率，倍率按 `EconomyConfigData.comboTiers` 阶梯上浮，击杀金币受倍率影响。
- **关卡与波次**：每关固定波数（`wavesPerLevel`），每波敌人数随关卡与波次增长；每 `bossEveryLevels` 关的第 `bossWaveIndex` 波出 Boss（三阶段）。
- **商店**：通关一关进入随机商店（武器 / 城墙 / 词条三类报价），可花金币购买、花金币重刷、看模拟广告免费重刷。
- **结算**：通关结算有金币奖励，可看模拟广告让本关金币 ×2（每日次数上限见 `AdsConfigData`）。
- **装备槽**：随关卡逐步解锁（`slotUnlockLevels`），已拥有武器可在结算/商店里装备。

## 二、目录结构

| 路径 | 作用 |
| --- | --- |
| `Assets/Scripts/Core` | 事件总线、对象池、随机源、数学工具、运行状态、GameRuntime 装配根 |
| `Assets/Scripts/Combat` | 敌人、子弹、命中与护盾判定 |
| `Assets/Scripts/Waves` | 波次生成、难度曲线 |
| `Assets/Scripts/Run` | 经济、连杀、武器、城墙、升级、商店、广告、存档、埋点 |
| `Assets/Scripts/View` | 程序化美术（SpriteFactory）、合成音效（AudioBus）、战斗表现（BattleView）、瞄准输入 |
| `Assets/Scripts/UI` | uGUI 五面板（菜单 / 战斗 HUD / 结算 / 商店 / 结束） |
| `Assets/Scripts/Bootstrap` | 场景入口 GameBootstrap |
| `Assets/Editor` | 场景生成、WebGL 构建、抖音目录后处理、CI 自检 |
| `Assets/Resources/Config` | 数值配置（武器 / 敌人 / 词条 / 调参），改数值不用改代码 |
| `Assets/Scenes/Main.unity` | 主场景（生成产物，勿手改；改参数后重跑菜单 1） |

## 三、在 Unity 里跑

1. 用 Unity 2022.3.62f3c1 打开本工程，打开 `Assets/Scenes/Main.unity`，点 Play。
2. 编辑器里首次运行会 `Assets/Scripts/Bootstrap/GameBootstrap.cs` 自动加载配置并开一局。
3. 菜单栏 `Gunplay` 下有四个入口：
   - **1. 重建主场景**：重建 `Main.unity` 并写竖屏 PlayerSettings（改过场景相关代码后跑）。
   - **2. 校验主场景结构**：检查五个根物体、组件引用、相机正交、Build Settings。
   - **3. 运行逻辑自检**：不开画面跑完整流程（战斗 60 秒 → 结算 → 商店 → 购买边界 → 下一关），日志 `E:/UnityProject/_ci/selftest.log`。
   - **4. 构建 WebGL（含抖音目录）**：出包到 `Build/WebGL`，并复制成抖音工程结构 `Build/Douyin/gunplay-siege-defense`。

## 四、抖音小游戏接入（需要你操作）

1. 打开抖音开发者工具（或关联的字节开发者工具），导入 `Build/Douyin/gunplay-siege-defense`。
2. 把 `project.config.json` 里的 `appid` 占位替换成你的小游戏 appid（文件里已标 `// TODO`）。
3. `game.json` 已按竖屏、隐藏状态栏、4×10 秒网络超时写好，可按需微调。
4. **注意**：Unity WebGL 产物要在抖音小游戏环境里真正跑起来，还需要接一层平台适配（`tt` 的 canvas/输入/音频桥接，官方叫「Unity WebGL 小游戏适配」）。当前交付的是标准 WebGL 包 + 抖音小游戏工程外壳；适配层需要你确认走官方适配方案后再接（这条已标 TODO，不是遗漏）。

## 五、调参

- 武器 / 敌人 / 词条数值：`Assets/Resources/Config/weapons.json`、`enemies.json`、`upgrades.json`。
- 波次、难度、经济、商店、广告、城墙：`Assets/Resources/Config/tuning.json`。
- 配置结构与默认值见 `Assets/Scripts/Core/ConfigData.cs`；改完 JSON 直接生效，无需重新构建场景（构建包里会重新打包）。

## 六之二、屏幕适配（本次修复）

- `Assets/Scripts/UI/UiRoot.cs`：新增 `autoFitAspect`，按屏幕宽高比自动切换 CanvasScaler 缩放基准（宽屏按高度、超窄屏按宽度），非 9:16 屏幕不再横向裁切界面。
- `Assets/Scripts/View/CameraFitter.cs`（新增）：运行时按宽高比放大正交尺寸（`size = max(9.6, 5.4 / aspect)`），9:19.5 长屏手机也不会裁掉战场左右边界。
- `Assets/Editor/DouyinBuildPostprocess.cs`：全屏样式升级为 v2，网页产物与抖音包都会铺满容器并隐藏 Unity 页脚（`#unity-footer` 等），同时保留 v1 幂等标记。

| 环节 | 入口 | 结果位置 |

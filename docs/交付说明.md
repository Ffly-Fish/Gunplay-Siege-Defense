# 交付说明 —— 枪法守城闯大关（Gunplay Siege Defense）

竖屏 9:16 定点守城射击小游戏，Unity 2022.3.62f3c1 + 2D URP，目标平台：抖音小游戏（WebGL）。
本版按 `docs/manual_extract.md`（开发手册 v1.2 抽取稿）实现全部核心玩法与数值。

## 一、怎么玩

- **瞄准与开火**：第一根手指按下屏幕，炮口立刻转向该点；按住持续朝该方向齐射，抬起停火。屏幕上按住也可以拖动改变朝向。
- **城墙**：底部城墙有耐久，敌人碰到城墙掉耐久；耐久归零即本局结束。
- **连杀**：短时间内连续击杀触发倍率，倍率按 `EconomyConfigData.comboTiers` 阶梯上浮，击杀金币受倍率影响。
- **关卡与波次**：每关固定波数（`wavesPerLevel`），每波敌人数随关卡与波次增长；每 `bossEveryLevels` 关的第 `bossWaveIndex` 波出 Boss（三阶段）。
- **商店**：通关一关进入随机商店（武器 / 城墙 / 词条三类报价，同一批**不会出现重复奖励**；城墙分小修 / 加固 / 大修三档，越贵加固越多），可花金币购买、花金币重刷、看广告免费重刷。
- **结算**：通关结算有金币奖励，可看模拟广告让本关金币 ×2（每日次数上限见 `AdsConfigData`）。
- **装备槽**：随关卡逐步解锁（`slotUnlockLevels`），已拥有武器可在结算/商店里装备。

## 六之四、静态元素不显示（本轮修复的真实 bug）

- 现象：无论怎么改背景 / 城墙 / 弩炮，浏览器里始终只有纯色底，看不到城墙与炮台。
- 根因：`Assets/Scripts/View/SpriteActor.cs` 构造时默认 `GameObject.SetActive(false)`（为对象池复用设计），而 `BattleView.BuildBackground/BuildWall/BuildCannon` 建完静态元素后**从未激活**——静态层从首版起就没渲染过，只是程序化美术颜色接近底色所以一直没被发现。
- 修复：三个 Build 方法末尾各加 `SetActive(true)`（动态元素本来就由池子激活，不受影响）。
- 验证：重新出包后浏览器可见石板地面、底部棕色木堡与城门、枪塔，见 `docs/screenshots/battle.png`。

## 六之七、抖音 TTSDK 出包（本轮修复：色彩空间）

- **现象**：TTSDK Build Tool 出包报 `Error building Player: Incompatible color space with graphics API`，构建直接失败。
- **根因**：TTSDK 安装时把 WebGL 图形 API 固定成 WebGL 1.0（`ProjectSettings/ProjectSettings.asset` 的 `m_BuildTargetGraphicsAPIs` → `WebGLSupport`，`m_APIs: 08000000` = `OpenGLES2`，`m_Automatic: 0`），同时写入 `scriptingDefineSymbols: WebGL: TTSDK_MIX_ENGINE`；而工程色彩空间是 Linear，WebGL 1.0 不支持 Linear，Unity 在构建前检查就报错。我们克隆沙箱里同一处是 `m_BuildTargetGraphicsAPIs: []`（自动），所以之前用 `WebGLBuilder` 出包从没触发过。
- **修复**：`Project Settings → Player → Other Settings → Color Space → Gamma`（`m_ActiveColorSpace: 0`）；`Assets/Editor/BuildWebGL.cs` 的 `ApplyWebGLSettings()` 也强制 `PlayerSettings.colorSpace = ColorSpace.Gamma`，让 CI 构建与 TTSDK 出包口径一致。
- **Gamma 下复验**：克隆重建成功（wasm 8,188,136 B / data 4,175,130 B，比 Linear 版略大），浏览器实拍菜单与战斗画面正常、颜色略亮更干净（`docs/screenshots/menu.png`、`battle.png` 已换成 Gamma 版）。
- ⚠️ TTSDK 装完会改写 ProjectSettings（内存 512MB、调试符号开、数据缓存关、Brotli 压缩），**TTSDK Build Tool 与我们的 `Gunplay/4. 构建 WebGL` 两条路径择一，不要交叉覆盖**。

## 六之十、自己构建网页版时必须先关掉 TTSDK 混引擎

抖音 TTSDK 安装后会把 WebGL 切成「混合渲染引擎 + OpenGL ES 2.0」，这种包只能在抖音容器里跑；用浏览器打开会世界层全黑（能看到 HUD、能开枪，但看不到敌人和场景）。

在 Unity 里自己构建网页版的正确顺序：

1. 菜单 **Gunplay → 8. 切到浏览器可玩模式（关闭 TTSDK 混引擎）**，等编辑器重编译完成。
2. 正常 Build WebGL（Build Settings → Build，或菜单 Gunplay → 4）。
3. 用 http 服务打开（不能双击 file://）：双击工程根目录的 preview-pages.bat，或手动 python -m http.server。
4. 要回抖音出包前，先点 **Gunplay → 9. 切回抖音出包模式（开启 TTSDK 混引擎）**，再用 TTSDK Build Tool 出包。

只想拿现成可玩的网页版：直接用 `docs/`（已是干净构建，preview-pages.bat 可本地预览，推 GitHub Pages 即在线可玩）。

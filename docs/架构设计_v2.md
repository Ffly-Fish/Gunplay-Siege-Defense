> 工程：Unity 2022.3.62f3c1（2D URP）/ C# / 目标 抖音小游戏（WebGL 竖屏）。
> 玩法数值来源：`docs/manual_extract.md`（开发手册 v1.2 抽取稿）。项目约定见根目录 `AGENTS.md`。

## 1. 一句话结构

**一个纯 C# 模拟层（账本 + 规则）被一个 MonoBehaviour 引导层驱动，表现层与 UI 层只读状态、只订阅事件，数据全部来自 Resources 下的 JSON 与 PNG。**

```
┌──────────────────── 场景 Assets/Scenes/Main.unity（5 个根物体）────────────────────┐
│  GameBootstrap ──Update(dt)──► GameRuntime.Tick(dt)                              │
│  AimInput(IAimInput) ────────► 瞄准输入（鼠标 / 触摸）                            │
│  BattleView  ◄── 每帧只读 Enemies/Bullets/Lasers + 订阅事件 ──┐                   │
│  UiRoot      ◄── 订阅 GameStateChangedEvent，按状态切面板 ────┤                   │
│  MainCamera（正交 size 9.6 + CameraFitter）                  │                   │
└─────────────────────────────────────────────────────────────┼───────────────────┘
                         │                                    │
             ┌───────────▼────────────────────────────────────┴──────┐
             │            Core.GameRuntime（唯一门面）                │
             │   装配所有系统 · 帧循环 · 状态机 · 对外 API            │
             └──┬──────────────────────────────────────┬─────────────┘
                │                                      │
    ┌───────────▼───────────┐              ┌───────────▼────────────┐
    │ 模拟层（纯 C#，无渲染） │              │ Core 基础设施           │
    │ Combat / Waves / Run   │              │ EventBus / RunState    │
    │ = 规则 + 账本           │              │ ConfigData / ObjectPool│
    └───────────┬───────────┘              └───────────┬────────────┘
                │                                      │
    ┌───────────▼───────────┐              ┌───────────▼────────────┐
    │ 表现层 View（读 + 事件）│              │ UI 层（uGUI 代码搭建）  │
    │ BattleView/ArtLibrary  │              │ UiRoot + 6 个面板       │
    │ AudioBus/SpriteFactory │              │ UiPixelArt 运行时九宫格 │
    └───────────┬───────────┘              └────────────────────────┘
                │
    ┌───────────▼───────────────────────────────────────────────────┐
    │ Resources/  Config/*.json · Art/Sprites/*.png · Art/Audio/*.wav · Fonts/MainFont.ttf │
    └───────────────────────────────────────────────────────────────┘
```

**依赖方向**：Bootstrap → Core（门面）→ 模拟层；View / UI 只依赖 Core 暴露的属性与事件，互不引用。模拟层只在 Core 里用到 `Vector2/Mathf`，不挂 MonoBehaviour、不读 `Time.time`，因此能在 batchmode 无头跑完 60 秒战斗（`CiSelfTest`）。

## 2. 启动与装配

```
Awake()  : Screen.orientation = Portrait
           ConfigDatabase.LoadFromResources()      // 4 张 JSON 表
           new GameRuntime().Initialize(config, aimInput, verboseTracking, randomSeed)
           if (autoStartBattle) StartNewRun()
Update() : runtime.Tick(Time.deltaTime)
OnDestroy(): runtime.Dispose()
```

`GameRuntime.Initialize` 装配顺序（新增系统必须插在这里，并保证被依赖者在后）：

| 顺序 | 系统 | 构造签名 | 职责 |
|---|---|---|---|
| 1 | `TrackSystem` | `(bool verbose)` | 埋点 |
| 2 | `SaveSystem` | `(AdsConfigData)` | 只存统计 + 每日广告次数（`PlayerPrefs` key `gunplay_save_v1`） |
| 3 | `UpgradeSystem` | `(ConfigDatabase, RunState)` | 词条等级 → 属性加成 |
| 4 | `WallSystem` | `(GateConfigData, RunState, EventBus)` | 城门耐久 / 加固 / `EquipAllOwned()` |
| 5 | `ComboSystem` | `(EconomyConfigData, RunState, EventBus, UpgradeSystem)` | 连杀窗口 / 倍率 / 档位 |
| 6 | `EconomySystem` | `(EconomyConfigData, RunState, EventBus, ComboSystem)` | 金币收支、暴击结算 |
| 7 | `EnemySystem` | `(ConfigDatabase, RunState, EventBus, ComboSystem, EconomySystem, WallSystem)` | 敌人池、移动、受击、破城 |
| 8 | `BulletSystem` | `(ConfigDatabase, RunState, EventBus, EnemySystem, IRandomSource)` | 子弹池、飞行、命中 / 穿透 / 爆炸 |
| 9 | `WeaponSystem` | `(ConfigDatabase, RunState, EventBus, BulletSystem, EnemySystem, UpgradeSystem, IRandomSource)` | 开火节奏、弹匣、换弹、激光、手雷 |
| 10 | `WaveSystem` | `(ConfigDatabase, RunState, EventBus, EnemySystem, DifficultySystem, EconomySystem, IRandomSource)` | 刷怪、难度、关卡结算 |
| 11 | `ShopSystem` | `(ConfigDatabase, RunState, EventBus, EconomySystem, WallSystem, UpgradeSystem, IRandomSource)` | 三张报价、购买、重刷 |

`DifficultySystem` 由 `WaveSystem` 内部持有（`new DifficultySystem(config.Tuning.difficulty)`）。

## 3. 状态机

```
 Menu ──StartNewRun / RestartRun──► Battle ──PauseGame──► Paused
   ▲                                  │  ▲                  │
   │ ReturnToMenu            ResumeGame│  └──────────────────┘
   │                                  │
   │        LevelClearedEvent         │ ContinueFromShop
   │  Result ◄──────────── Battle ─────┴───────► Shop
   │     │ ContinueFromResult ───────► Shop
   │     └──（城门耐久 0）──► GameOver ──RestartRun──► Battle
   └───────────────────────────────────────────────────────
```

- 状态存 `GameRuntime.state`，统一走 `SetState()`（同状态不重复广播），广播 `GameStateChangedEvent`。
- **暂停实现**：`Tick()` 开头 `if (state != GameState.Battle) return;` —— 状态不是 Battle 时模拟层整体冻结。新系统必须挂在 `Tick` 之下才会被一并暂停。
- `UiRoot` 按状态切面板：`Battle | Paused` 显示 HUD，`Paused` 额外显示暂停面板。

| 对外入口（UI 调用） | 作用 |
|---|---|
| `StartNewRun()` / `RestartRun()` | 开新一轮（起始武器 `config.Weapons[0]`） |
| `ContinueFromResult()` | 结算 → `Shop.Roll()` → Shop |
| `ContinueFromShop()` | `run.StartNextLevel()` → `Wall.RestoreFull()` → `Wall.EquipAllOwned()` → `Weapons.RefillAll()` → 清场 → `Wave.StartLevel()` → Battle |
| `BuyOffer(int index)` / `RerollShop()` | 购买 / 重刷（index 是 `Offers` 稳定下标，买完不移除） |
| `WatchAdDoubleGold()` / `WatchAdFreeReroll()` | 激励视频：有 tt 走真实广告，无则模拟；**回调 completed 才发奖** |
| `PauseGame()` / `ResumeGame()` / `SkipCurrentLevel()` | 暂停 / 继续 / 一键通关（`WaveSystem.ForceClearLevel()`） |
| `ReturnToMenu()` / `SetSoundOn(bool)` / `Track(...)` | 回主菜单 / 声音开关 / 埋点 |

## 4. 一帧的数据流

```
AimInput（屏幕 → 世界坐标）
   │
GameRuntime.Tick(dt)
   ├─ direction = AimWorldPos - BattleField.GetBarrelPivot()     // 枪塔旋转轴 (0,-9.15)
   ├─ muzzle    = BattleField.GetMuzzleTip(direction)            // 旋转后的枪口尖端
   ├─ WeaponSystem.Update(dt, aiming, muzzle, direction, aimPos)  // 冷却/弹匣/换弹/激光 → BulletSystem.Spawn*
   ├─ BulletSystem.Update(dt)                                    // 直线/弧线飞行、命中盒、穿透、爆炸、出屏回收
   ├─ EnemySystem.Update(dt)                                     // 走向城门、护盾角、攻击城门
   ├─ ComboSystem.Update(dt)                                     // 连杀窗口衰减
   ├─ WaveSystem.Update(dt)                                      // 刷怪、清波、关卡结算
   └─ if (Wall.IsBroken) HandleGameOver()
```

命中链：`Bullet → EnemySystem.Hit` → 护盾判定（挡下 / 命中）→ 扣血 → `EnemyDamagedEvent` → 死亡 `EnemyKilledEvent`（金币 + 连杀）→ 经济结算 → `GoldChangedEvent` / `ComboChangedEvent`。

## 5. 事件总线（17 个事件，`Core/GameEvents.cs`）

`EventBus.Subscribe<T>/Unsubscribe<T>/Publish<T>/Clear()`，泛型只接受 class。

| 事件 | 发布者 | 主要订阅者 |
|---|---|---|
| `EnemySpawnedEvent` / `EnemyDamagedEvent` / `EnemyKilledEvent` | `EnemySystem` | `BattleView`（生成 / 闪白 / 死亡动画 / 飘字） |
| `ShieldBlockedEvent` / `ShieldBrokenEvent` | `EnemySystem` | `BattleView`（挡弹提示 / 破碎特效） |
| `ExplosionEvent` | `BulletSystem` | `BattleView`（爆炸帧 + 震屏 + 音效） |
| `GateDamagedEvent` | `WallSystem` | `BattleView`（城门变色）、`BattleHud`（耐久条） |
| `GoldChangedEvent` / `ComboChangedEvent` | `EconomySystem` / `ComboSystem` | `BattleHud`、`ShopPanel` |
| `WaveStartedEvent` / `WaveClearedEvent` | `WaveSystem` | `BattleHud` |
| `LevelClearedEvent` | `WaveSystem` | `GameRuntime`（转 Result + 存统计）、`ResultPanel` |
| `GameStateChangedEvent` | `GameRuntime.SetState` | `UiRoot`、各面板 |
| `ShopRolledEvent` / `ShopPurchasedEvent` | `ShopSystem` | `ShopPanel` |
| `WeaponFiredEvent` | `WeaponSystem` | `BattleView`（枪口火光 / 音效）、`CiSelfTest`（多枪齐射断言） |
| `AdRewardFinishedEvent` | `GameRuntime` | 预留（广告结果反馈） |

约定：**一次性反馈走事件，持续性状态每帧拉取**（`runtime.Enemies/Bullets/Lasers/Wave/Wall/Shop`）。

## 6. 关键契约（改动前必读）

### 6.1 世界坐标（`Core/BattleField.cs`，唯一真源）

| 常量 | 值 | 含义 |
|---|---|---|
| `HalfWidth` / `HalfHeight` | 5.4 / 9.6 | 战场半宽高（10.8 × 19.2 世界单位） |
| `Muzzle` | (0, −8.2) | 枪口基准点（枪塔贴图顶边对齐此处） |
| `BarrelHalfLength` | 0.95 | 旋转轴到枪口的距离 |
| `GetBarrelPivot()` | (0, −9.15) | **枪塔旋转轴**，所有瞄准角度绕它算 |
| `GetMuzzleTip(dir)` | pivot + dir·0.95 | **旋转后的真实枪口**：子弹 / 激光 / 瞄准线 / 枪口火光都用它 |
| `GateLineY` | −8.6 | 城门受击线 |
| `SpawnLineY` / `BulletDespawnY` | 10.6 / 11.5 | 敌人出生线 / 子弹回收线 |
| `BulletSpawnOffsetStraight` / `Arc` | 0.3 / 0.35 | 出弹点沿方向前移，避免压住枪口贴图 |

相机：正交 `size = 9.6` + `CameraFitter` 在超窄屏自动放大到 `max(9.6, 5.4 / aspect)`，保证战场宽度不被裁切。

### 6.2 账本（`Core/RunState.cs`）

`level / wave / gateHp / gateMaxHp / gold / combo / lastKillTime / totalKills / bestCombo / ownedWeapons / equippedWeapons / weaponStates / upgrades / wallReinforceLevel / rerollsThisLevel / currentLevelStats`。
武器**拥有即装备**：`UnlockWeapon(weaponId, magazine)` 直接进 `equippedWeapons`（已取消槽位上限，`slotUnlockLevels` 仅兼容保留）。

### 6.3 配置表（`Core/ConfigData.cs` ↔ `Resources/Config/*.json`）

| JSON | 顶层 key | 结构 |
|---|---|---|
| `weapons.json` | `weapons` | 伤害 / 射速 / 弹匣 / 弹丸数 / 散布 / 穿透 / 伤害类型 / 解锁价与关卡 / 暴击 / 弹速 / 弧抛 / 爆炸半径 / 在飞上限 / 激光能量·过热·角色 |
| `enemies.json` | `enemies` | HP / 速度 / 护甲 / 金币 / 破城伤害 / 护盾周期与正面弧度 / 半径 / 出现波次 / 权重 / Boss 阶段 |
| `upgrades.json` | `upgrades` | 类别 / 基础价 / 最高级 / 每级数值 / 适用武器 |
| `tuning.json` | `waves, difficulty, economy, shop, gate, combat, ads` | 波次数量与间隔、难度曲线、经济与连杀档位、商店权重与重刷、城门耐久、战斗上限、广告次数 |

改数值不需要改代码；加字段需同步 `ConfigData` 与 JSON。

### 6.4 枚举（`Core/GameEnums.cs`）

`GameState{Menu,Battle,Paused,Result,Shop,GameOver}`、`DamageType{Normal,Explosive,Piercing}`、`EnemyKind{Grunt,Runner,Shield,Flyer,Heavy,Boss}`、`UpgradeKind{Damage,FireRate,Pellets,Pierce,Magazine,Crit,ComboWindow}`、`ShopOfferKind{Weapon,Wall,Upgrade}`。

## 8. UI 层（`Assets/Scripts/UI`，3,086 行）

```
UiRoot（Canvas ScreenSpaceOverlay + CanvasScaler 1080×1920 + GraphicRaycaster + EventSystem 自动创建）
├── MenuPanel        菜单 / 生涯战绩 / 开始
├── BattleHud        城门耐久 / 关卡·波次 / 金币 / 连杀 / Boss 血条 / 武器槽（每行 4 个）+ 暂停 + 一键通关
├── PausePanel       暂停中（继续 / 重新开始 / 回主菜单）
├── ResultPanel      第 N 关通过 + 本关结算 + 金币×2 + 进入商店
├── ShopPanel        三张报价卡 + 重刷 + 免费重刷 + 出征
└── GameOverPanel    战果 + 再来一次 / 回主菜单
```

- `UiPanelBase`：`CanvasGroup` 显隐 + `SetVisible` 幂等 + 延迟绑定 `GameRuntime`。
- `UiPixelArt`：运行时生成 32×32 九宫格像素皮肤（Point 采样、`Image.type = Sliced`），不落 PNG，减小包体。
- `UiBuilder` / `UiTheme`：布局、配色、字号统一入口；`UiSafeArea` 处理刘海。
- 全部界面代码搭建，不依赖 prefab，便于无头校验。

## 13. 已知约束

- 模拟层不碰渲染 → 表现必须能"每帧从状态重建"，禁止在 View 里存唯一真相。
- `SpriteActor` 默认隐藏（对象池）：静态元素创建后必须 `SetActive(true)`。
- 暂停靠 `Tick` 提前返回：新系统挂进 `Tick` 才会被冻结。
- `GameRuntime.Instance` 由场景里的 `GameBootstrap` 创建；`UiRoot` 会自建，但**若打开的是空场景 SampleScene，界面能显示却点不动**（没有 GameBootstrap）。
- 新增 `.cs` 必须同时回传 `.meta`，否则场景引用变 Missing Script。

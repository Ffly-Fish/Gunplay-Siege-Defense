# 素材清单与美术接入规范（v1）

> 本文档由 Lead 维护，是本项目"视觉风格唯一口径"。所有素材必须符合本文档的尺寸、命名与目录约定，放进去即自动生效，**不需要改代码**。

## 一、风格决策（已定）

**像素奇幻（Pixel Fantasy）· 下压式守城视角。**

- 视角：玩家在屏幕底部守卫城门，敌人从屏幕上方成排向下推进（俯视偏正面）。
- 画风：16-bit 像素风，中等尺寸（敌人 64–96 px、Boss 192 px），硬边缘（无抗锯齿）、深色描边、2–3 阶明暗。
- 配色：与现有 UI 一致 —— 深底色 `#14161F`、金色高亮 `#FFC63C`、城门青绿、敌人暖红/褐、特效橙黄。
- 内容基调：中世纪城墙 + 奇幻怪潮 + 魔法弹道。武器全部按"奇幻化"命名（火枪=手枪、三眼铳=步枪…），**不出现现代枪械与机械建筑**。
- 动画：敌人行走 4 帧循环；爆炸 6 帧；受击火花 4 帧；枪口火焰 3 帧。
- 为什么这样选：本地素材库（`E:\游戏素材`）已有一整套同源像素奇幻素材（Fantasy Dreamland 系列 + Pixel Battlers 怪物 + 法术 VFX + 通用音效），同一位画师、同一调色板，改造量最小且天然统一；网络素材只作为缺口补充。

## 二、放置位置（放进去即生效）

```
Assets/Resources/Art/
  Sprites/            每张精灵一张 PNG（透明底）
  Sprites/<key>.png           单帧
  Sprites/<key>_1.png ...     帧序列（首帧是 <key>.png，其后从 _1 连号，缺号即视为结束，最多 12 帧）
  Audio/<key>.wav | .ogg      音效（同名 key 会覆盖合成音效）
  README.md                   说明
```

- 导入规则已自动接管（`Assets/Editor/ArtImportPostprocess.cs`）：像素风 = Sprite 类型、Point 采样、关闭 mipmap、无压缩、PPU 50（50 像素 = 1 世界单位）、最长边 2048；音频统一单声道 + Vorbis（质量 0.6）。
- 文件缺失 = 自动回退当前程序化美术，**不会报错**，因此可以分批放、先放先看。
- 代码加载层：`Assets/Scripts/View/ArtLibrary.cs`（精灵 / 帧序列 / 音效），`SpriteFactory` 与 `AudioBus` 已优先读取外部资源。

## 八之二、用户下载素材的取舍（重要）

用户在 `Assets/外部素材/` 放了 6 个包，评估结果：

| 素材包 | 结论 | 原因 |
| --- | --- | --- |
| `kenney_tower-defense-top-down.zip` | 未使用 | 扁平矢量风（绿草块、灰炮塔），与已落地的 Fantasy Dreamland 像素风冲突 |
| `kenney_medieval-rts.zip` | 未使用 | 同上，扁平矢量 |
| `Ninja Adventure - Asset Pack.zip` | 未使用 | 虽是像素风但为 16px 小图（弩 15×7），放大后糊 |
| `kenney_ui-pack.zip` | 备用 | 若后续要换 UI 底板可挑九宫格图，需先统一到像素风 |
| `kenney_interface-sounds.zip` | 备用 | 音量/音色与现有 18 个音效风格不同，暂不混用 |
| `pumpkin_dude.png` | 备用 | 单张角色图，暂未用 |

结论：**首版统一以 Fantasy Dreamland 像素风为唯一来源**，弩炮与炮台无现成素材 → 用同色板自绘，保证与敌人一致。
